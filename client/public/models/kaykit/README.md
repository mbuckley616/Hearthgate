# KayKit models

Free tiers of four packs by Kay Lousberg (www.kaylousberg.com), downloaded from itch.io on 2026-10-14 for the art sources Michael chose (`docs/decisions.md`, `docs/style-guide.md`). All CC0: free for commercial use, no attribution required; each folder keeps the pack's own `License.txt`. Only the glTF/GLB files and their colour textures are here; the FBX, OBJ and sample scenes were left out.

| Folder | Pack | What is here |
| --- | --- | --- |
| `adventurers/characters/` | [Adventurers 2.0](https://kaylousberg.itch.io/kaykit-adventurers) | Barbarian, Knight, Mage, Ranger, Rogue, Rogue_Hooded (GLB, rigged on Rig_Medium, textures embedded) |
| `adventurers/weapons/` | the same | swords, axes, bows, crossbows, shields, staff, wand, quiver, mugs (glTF + one texture per character) |
| `animations/` | [Character Animations 1.1](https://kaylousberg.itch.io/kaykit-character-animations) | Rig_Medium clips: General, MovementBasic, MovementAdvanced, CombatMelee, CombatRanged, Simulation, Special, Tools |
| `dungeon/` | [Dungeon Pack 1.1](https://kaylousberg.itch.io/kaykit-dungeon-pack) | all 211 pieces: walls, floors, stairs, pillars, torches, barrels, crates, chests, banners, furniture; one `dungeon_texture.png` |
| `hexagon/` | [Medieval Hexagon 1.0](https://kaylousberg.itch.io/kaykit-medieval-hexagon) | eight green buildings for the village scale test: tavern, market, blacksmith, church, two homes, well, windmill; one `hexagons_medieval.png` |

To add pieces, download the pack's free tier again and copy the glTF files across; keep each pack's texture beside its glTF files, because the glTF files name it by a relative path.
