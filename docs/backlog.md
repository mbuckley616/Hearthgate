## Found in play (the critic)

Confirmed bugs from headless play and the lag lab, one line each with the commit and the steps. The builder takes these before new work in the current phase.

- [ ] **(Fable)** Movement speed falls with frame rate (f415a88): the client sends one input per `setInterval` callback and drops the ticks a busy main thread misses, so a 1.5 s hold covers 9.3 m at 60 fps, 5.7 m at 21 fps, 2.1 m at 10 fps. Steps: two tabs in one headless Chromium at 1280 x 720, hold A in one; same cause as `tests/two-players.e2e.ts` failing (still failing in Session 15: 0.9 m in 700 ms headless). Touches the client input loop and the server's per-tick input cap and flood limit; see `proposals.md`.
- [x] Controls hint covers ability slots 1 and 2 between 601 and ~750 px wide (f415a88): 109 px overlap at 640 x 400 (phone landscape). Steps: open the client at 640 x 400; `docs/critic/2026-10-04-hint-over-slots-640px.png`. (Session 11: the hint wraps left of the slots; 640 x 400 case in `tests/mobile.e2e.ts`)
- [x] Respawn and wipe teleports count as snaps and corrections (f415a88): `reconcile` counts the server's move to the spawn as a >2.5 m error, so the HUD corrections and `__hg.snaps` rise on every respawn. Steps: two pages, let the goblin down both, compare `__hg.snaps` before and after the respawn. (Session 12: dead to standing, and the first patch, are placements; `tests/reconcile-placement.ts` in `npm run test:net`)
- [ ] **(Fable)** Corrections on a clean link come from tick timing, not the network (1441983): the server applies up to two queued frames at one tick's `now` and fills a starved tick with a neutral frame, while the client replays each frame at its own tick, so a dodge, swing or cooldown that ends near a shifted frame is corrected by up to 0.8 m. 61 of 63 corrections at 50 ms fell within 750 ms of a swing, dodge or Cleave press; 11 to 24 a minute run to run. Steps: `npm run lab -- --only "50 ms"` with a recorder on the HUD count (critic.md, 2026-10-05). Same input path as the frame-rate item above.
- [ ] Awake enemies press into a wall instead of using their room's door when the target leaves the room (1441983): no way round, so a chaser slides to a corner and stays while the target is within 1.5x aggro. Steps: Warrens, walk into the guard room until the Shieldbearer wakes, walk back out east to (2, 3); it slides along the inside of the hall's north wall to about (-1, 8.9) and stays. A goblin sat there in chase for 8+ s in another run.
